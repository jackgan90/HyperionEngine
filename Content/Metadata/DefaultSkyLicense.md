# Default sky

Cloudy daylight is derived from Poly Haven's `kloofendal_48d_partly_cloudy_puresky`, released under CC0. Source attribution and license were recorded in HyperionAssets on 2026-09-13 and moved with the baked products.

- Asset: https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
- License: https://polyhaven.com/license
- Source URL and SHA-256: [DefaultSkySources.json](DefaultSkySources.json)

The HDR source is interpreted as linear scene-referred RGB without per-image normalization. The engine-owned CPU bake produces the radiance cube, GGX specular cube and diffuse SH coefficients; the BRDF LUT is shared Engine content. Normal runtime requires only the native assets.
